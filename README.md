# StoryFrame — AI Storyboard Generator

A web application that automatically generates cinematic storyboards from a text narrative, using Artificial Intelligence.

🔗 [Live App](https://storyboard-generator-three.vercel.app) | 📁 Repository

## About the Project

StoryFrame solves a real problem for content creators and multimedia students: building a visual script is a slow, manual process. With this tool, the user describes their narrative and the AI automatically structures the scenes, defining shot framing, camera movements, transitions, and mood.

Developed for the Software Engineering course — ESTG · UNIPVC · ECGM.

## Features
- ✅ AI-generated storyboard from a text narrative
- ✅ 9 cinematic genres (Cinematic, Documentary, Advertising, Music Video, Animation, Video Game, TV Series, Short Film, Institutional)
- ✅ 4 to 10 configurable scenes
- ✅ Shot type, camera movement, transitions, and mood per scene
- ✅ Individual scene regeneration
- ✅ Inline description editing
- ✅ PDF export
- ✅ Generation timer
- ✅ Character counter and clear button

## How to Use
1. Go to [storyboard-generator-three.vercel.app](https://storyboard-generator-three.vercel.app)
2. Select the genre and number of scenes
3. Write your narrative
4. Click GENERATE STORYBOARD
5. Explore the generated scenes — regenerate or edit each one
6. Export to PDF with the EXPORT / PRINT button
